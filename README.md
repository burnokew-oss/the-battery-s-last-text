One line of at most 200 characters: the phone battery's final message to the charger it waited for all day. A breakup text, not a eulogy — the charger spent the day charging the iPad, the earbuds, even the toothbrush, everyone but the battery holding on at 1%.

> i held on at 1% all day while you charged the ipad, the earbuds, even the toothbrush. so this is my last text: it's not me, it's you. don't text back.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` and prints it. Pure standard library, deterministic.
